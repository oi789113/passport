# 美国护照 3D 模型

GitHub Pages 静态网站，支持旋转、缩放、重置视角与下载 GLB 模型。

封面矢量素材：[United States Passport.svg](https://commons.wikimedia.org/wiki/File:United_States_Passport.svg)，Wikimedia Commons 标记为公共领域（PD-USGov）。原作者 Siirski；字体修订 FireDragonValo。Three.js 授权见 THREE_LICENSE.txt。

`index.html` 引用已打包的 `viewer.bundle.js` 和 `us_passport.glb`，可直接部署到静态主机。
